# 🧠 Human vs AI — Cognitive Intelligence Arena

> Can human intelligence outperform artificial intelligence?

Human vs AI is an experimental AI-powered cognitive challenge platform
designed to compare human reasoning with artificial intelligence.

The system evaluates not only the final answer, but also reasoning,
accuracy, creativity, consistency and decision-making.

---

## 🚀 Vision

The goal is not simply to ask:

"Who is smarter — Human or AI?"

Instead, this project investigates:

- How humans think
- How AI reasons
- Where humans outperform AI
- Where AI has an advantage
- How human and artificial intelligence can complement each other

---

## 🤖 AI-Powered Features

### 🧠 Intelligent Reasoning Analysis
AI analyzes the user's response and evaluates the quality of reasoning.

### 🎯 Cognitive Scoring
Each attempt can be evaluated using:

- Accuracy
- Reasoning Quality
- Creativity
- Speed
- Consistency

### ⚡ Adaptive Difficulty
The difficulty dynamically changes according to the user's performance.

### 🔍 Explainable AI
AI provides an explanation of why an answer was considered
strong, weak or incorrect.

### 📊 Performance Dashboard
Users can visualize their performance through:

- Accuracy
- Average response time
- Cognitive score
- Strengths
- Weaknesses
- Human vs AI comparison

### 🧩 Multiple Challenge Modes

- Logic
- Mathematics
- Pattern Recognition
- Critical Thinking
- Creativity
- Decision Making
- General Intelligence

### 🏆 Leaderboard

Users can compare their cognitive performance with other participants.

---

## 🧪 Human vs AI Experiment

For each challenge:

1. Human receives the problem
2. Human submits an answer
3. AI solves the same problem
4. AI evaluates both responses
5. Scores are calculated
6. Results are visualized
7. AI provides feedback

---

## 📈 Scoring Model

Example:

Human Score =
Accuracy + Reasoning + Creativity + Speed + Consistency

AI Score =
Accuracy + Reasoning + Confidence

The system then generates a comparative result.
